# Hammad Hanif Portfolio

A responsive static portfolio built with semantic HTML, modern CSS and vanilla JavaScript.

## Run locally

Open `index.html` directly, or serve the folder from a terminal:

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

## Deploy

Deploy the folder directly to Vercel, Netlify, GitHub Pages or any static web host. No build command or environment variables are required.
